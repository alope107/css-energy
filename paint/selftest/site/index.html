Dictionary RAM self-test

Chrome only. Load this page, wait a few seconds, then reload once: the first load writes the dictionaries, the reload reads them. WAIT means a probe never decoded.

A · dcz decoding works on this host

A dictionary with a literal match pattern, and a probe compressed against it. NO DCZ is normal on the first load. Still NO DCZ after a reload means the host strips Use-As-Dictionary or Content-Encoding: dcz (e.g. Cloudflare's Shared dictionaries setting is not on passthrough). Nothing else can work.

B · placeholders in header values

The dictionary's match pattern is /t1/:k/r/*, filled in from its own path.

C · headers follow the request path of a 200 rewrite

Dictionary and probes live in /shared/ but are requested as /t2/a/… and /t2/b/…. PASS: cell a decodes, never-written cell b does not. LEAK: both decode, so the namespaces collapsed. FAIL/WAIT: the rewrite lost the headers; you would need one file per cell and value.

D · Vary: * survives

A reused write URL must still re-register a dictionary, which needs Vary: * to reach Chrome. This one takes four pages: start the chain, and click "next" on each, waiting a second on each page.

  1. Run it on *.pages.dev and on your custom domain; compare.
  2. Run it in a fresh profile (or Incognito) to rule out dictionaries left over from an earlier run.
