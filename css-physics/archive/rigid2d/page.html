A rigid body physics engine in pure CSS. No JavaScript: the page contains no script, and works with scripting disabled.

Drag any body with the mouse; grab it off-center to swing it.

Every style pass, state is read back from layout through view timelines; prediction, broadphase, SAT narrowphase and a Gauss–Seidel XPBD contact solve with friction, restitution and shock propagation run as __NPROPS__ registered custom properties across __NLEV__ nested elements, with @container style() queries keeping far-apart pairs and non-touching contacts from being declared at all; the next state is written back into layout. __NC__ candidate contacts, 10 bodies, 120 steps per second.
