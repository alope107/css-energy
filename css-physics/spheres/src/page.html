spheres.css

Hundreds of colliding spheres, simulated in pure CSS. The page contains no script and works with scripting disabled.

This browser has no scroll-driven animations, which the engine reads its state through, so nothing will move. Firefox has them from version 159; in Firefox 158 set layout.css.scroll-driven-animations.enabled to true in about:config.

Drag any sphere with the mouse; it moves in the plane facing the camera.Tap a sphere to pick it up, drag anywhere to move it, and tap again to let go. Fewer spheres run faster; switching the count restarts the scene.
