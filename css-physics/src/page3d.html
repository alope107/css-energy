rigid3d.css

A 3D rigid body physics engine in pure CSS. The page contains no script and works with scripting disabled. Now with buttons on the boxes →

This browser has no scroll-driven animations, which the engine reads its state through, so nothing will move. Safari has them from version 26, Firefox from version 159; in Firefox 158 set layout.css.scroll-driven-animations.enabled to true in about:config.

Drag any body with the mouse. It moves in the plane facing the camera; grab a box off-center to swing it.Touch a body and drag it; it moves in the plane facing the camera. Let go to drop it. Fewer bodies run faster; switching the count restarts the scene.

__ENGINES_SENTENCE__ Every style pass reads each body's position, orientation and velocity back from layout through view timelines (__NREG__ registers for __NMAX__ bodies). Prediction, broadphase, a box/box SAT face manifold, closest-point sphere tests and a Gauss–Seidel solve with world-space inertia tensors, friction, rolling resistance, restitution and shock propagation run as up to __NPROPS__ custom properties across __NLEV__ nested elements: one element per Gauss–Seidel round, each body's running totals inherited from round to round. Every rule is gated by an @container query that names its body's container (b0, b1, …), and a level carries that name only while the body is awake or near an awake one, so the rules of a sleeping neighbourhood are rejected without being evaluated. Picking unprojects the pointer through the camera and ray-casts box slabs and spheres; on touch screens each body carries a scrollable handle, and the drag is that handle's scroll offset. The next state is written back into layout; the picture is CSS 3D transforms with per-face lighting. Bodies that come to rest fall asleep (a scene placed at rest loads asleep), and once everything is still the style engine has next to nothing to do.
